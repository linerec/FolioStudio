## Known limitations

Of 398 registered commands, 343 are available and 55 are intentionally withheld. These cover data outside the project (32), engine process control (12), passwords and secrets (6), printers (4) and one drag-only action. Call `coverage` for the reason behind each entry.

MCP access starts off. In a fresh Windows profile, `appConnection` returned `attached: false` and explained how to enable the connection in Preferences. File writes and database refresh each require separate permission.

Windows has no publisher signature. The macOS app is ad-hoc signed and has not been notarized. The Apple Silicon archive includes the executable MCP server with its Unix execute permission. The live connection was tested on Windows. macOS and Linux still need testing on hardware. Linux users can build from source.
