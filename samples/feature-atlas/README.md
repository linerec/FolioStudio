# Feature Atlas

This 51-page compatibility sample contains 181 examples in 29 groups. It was created by scripts in InDesign 2025. The linked artwork, data and media were generated for the sample.
Choose **Help ▸ Open Feature Sample (Atlas)** to open a project with all its links. To use **File ▸ Import**, copy `Feature_Atlas.idml` and the `Links` folder into your project first, then choose that IDML file.

InDesign 2025에서 스크립트로 만든 호환 시험 문서입니다. 51쪽에 29개 분류의 표본 181개가 있으며, 그림·자료·미디어도 이 견본을 위해 만들었습니다.
**도움말 ▸ 기능 표본 열기 (Atlas)**를 누르면 그림을 포함한 견본 프로젝트가 열립니다. **파일 ▸ 가져오기**를 쓰려면 먼저 `Feature_Atlas.idml`과 `Links` 폴더를 프로젝트 폴더에 함께 복사한 뒤 그 IDML을 고르세요.
